# Limits

* [CORS in the web version](cors-in-the-web-version.md) - In GeoLibre web a service whose server sends no CORS headers cannot be read; the same service works in GeoLibre Desktop.
* [Strip credentials](strip-credentials.md) - Before GeoLibre 3.3.0, and still for the development copy, GeoLibre counts the plugin's saved search as possible credentials; stripping them, or sharing the project, leaves the search out.
* [A search is not a project change](unsaved-search.md) - GeoLibre does not mark the project as modified after a search, so closing without saving loses the search without a question.
* [Project file names](project-file-names.md) - GeoLibre Desktop reopens from Open Recent only projects whose name ends with .geolibre or .geolibre.json.
* [An update needs a reinstall](update-needs-reinstall.md) - Before GeoLibre 3.3.0, when the registry gets a new version GeoLibre stops loading the installed plugin and shows it as failed, until it is uninstalled and installed again; 3.3.0 offers an Update.
* [Services that fail](services-that-fail.md) - The reasons a service of a record cannot be added, what the panel says for each, and what can be done.
