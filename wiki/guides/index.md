# Guides

* [Install the plugin](install.md) - Install from GeoLibre's Manage Plugins, from a zip, or by hand, and turn the plugin on.
* [Search the catalogue](search.md) - How to search RNDT from the panel, read the results and open a record.
* [Add layers to the map](add-layers.md) - From the detail view of a record, add WMS and ArcGIS layers as images and download WFS and ArcGIS features.
* [Share a search](share-a-search.md) - Two ways to pass a search on - a link that opens GeoLibre on a search, and a project that carries the search.
* [From the web version to Desktop](web-to-desktop.md) - Pick a record in GeoLibre web, save the project, open it in GeoLibre Desktop where every service can be read.
